# 🕵️ DevDetective

A modern GitHub profile finder and battle application built using HTML, CSS, and JavaScript.

This project uses the official GitHub REST API to fetch real-time GitHub user data and display it with a modern responsive UI.

---

# 🚀 Features

## 🔍 GitHub Profile Search

* Search any GitHub username
* Fetch live data using GitHub API
* Display:

  * Avatar
  * Name
  * Username
  * Bio
  * Join Date
  * Company
  * Location
  * Portfolio Link
  * Followers
  * Following
  * Public Repositories
  * Gists

---

## 📦 Repository Section

* Fetch latest repositories dynamically
* Show:

  * Repository Name
  * Stars
  * Language Badge
  * Last Updated Date
* Repositories open in a new tab

---

## ⚔️ Battle Mode

Compare two GitHub users using:

* Promise.all()
* Repository star calculation
* Winner & loser comparison system

Battle mode displays:

* Total Stars
* Followers
* Following
* Repository Count
* Join Date
* Location

---

## 🎨 UI Features

* Glassmorphism design
* Responsive layout
* Premium hover animations
* Animated loading spinner
* Glowing background effects
* Modern cards and buttons
* Mobile responsive

# 🌐 GitHub API

This project uses:

```bash
https://api.github.com/users/{username}
```

Example:

```bash
https://api.github.com/users/octocat
```

# ⚡ Installation

Clone the repository:

```bash
git clone https://github.com/YOUR_USERNAME/dev-detective.git
```

Open project folder:

```bash
cd dev-detective
```

Run using Live Server or open `index.html`.
